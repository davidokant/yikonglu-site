# 原页经文大字自动出框（11-08）

给没有句列坐标的章，从原页图直接找经文大字、与原文逐字对齐，生成 `_句列/<章>.json`。

流程（在本目录跑，读共享盘页图与原文）：
1. `allcells.py`：每页定版框、界栏（geo4：分段梳形拟合，能跟书页弯曲），切 10 列 × 20 格，存格子像素。
2. `labels.py`：用已有句列给格子打标（大字 / 章首圈 ○ / 其他）。
3. `align.py`：三类小网络（mlp3，权重 m3_all.pkl）给每格打分；按篇把原文（○＋各章字）与格子做动态规划对齐，缺页用中性虚格。
4. `val.py`：拿已有句列的 236 章对答案（11-08：全部对上）。
5. `gen.py <输出目录>`：只给没有句列、且不碰缺页的章写 json。

经验：经文大字落在固定字格上；“一”这类扁字单独认横画（hbar.py）；章内跳格加小罚分，免得整串错位。
