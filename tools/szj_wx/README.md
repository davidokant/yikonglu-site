# 三字经王相本原页逐组框（11-13）

底本：清王相《三字经训诂》1831 年和刻本（共享盘 PDF），53 个对开页（4000 宽）。

流程：wx_lines.txt 是每个对开页里大字（经文）各行的文字，右起读序，178 行 → geom.py 自适应找每行大字所在列（fix.py 手改四处错位：008、027、031、035）→ align.py 用 difflib 把讲义 101 组逐字对到王相本各行（讲义多出 22—24、26、69—75 十一组；76 组“廿二史”↔王相“十七史”）→ pages.py 按中缝拆成单页（对开右半在前，页号＝对开号×2，左半＋1）、按中缝边的版框竖线校平、缩到 1200 宽，每列按上下两半各三字切格 → 组框导出 tools/szj_julie.json（导出步骤见 export 段，在 pages.py 之后跑：每组每列取所含字格的并集）。viz.py 出核对图。

图片在图片仓库 sanzijing/pNNN.jpg（91 页）。build.py 的 build_szj 读 szj_julie.json 画 rect.hl；SZJ_YW 是逐组异文说明，SZJ_WX_NO 是王相本没有的组（页内标“补”）。
