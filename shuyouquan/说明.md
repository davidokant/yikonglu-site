# 一孔书院 · 书友圈（雏形）

Cloudflare Worker ＋ D1，服务端渲染、零依赖。结构借鉴 MIT 开源 cf-bbs Nexus、企鹅窝，代码自写。

- 第一版：网名＋密码注册（不要邮箱、手机）；入会邀请码进会员组；分区（门口公开，其余会员）；发帖回复；上官有理、孔照今两个角色账号（管理员发帖时可选“以谁的身份发”，帖子挂“一孔录原创角色·智器主持”）；角色定时帖（Cron 每 10 分钟查一次）；章页直达 /c/1.16（有帖跳帖，没帖在共读区发起）；管理页生成入会码、重置码、排定时帖、置顶、标已答；简单限流、蜜罐、同源检查。
- 不做（第二版再说）：私信、图片上传、邮件通知。
- 存储：一个 SQLite Durable Object（schema.sql 启动时自动建表），不用 D1。本机跑：npx wrangler dev --local。
- 部署：npx wrangler deploy --var ADMIN_CODE:<随机码>（首位管理员注册时填这个码；有了管理员就失效）。
- 域名：大陆打不开 workers.dev，要挂自家子域；yikonglu.com 解析目前不在 Cloudflare（11-09 核），挂 shuyuan.yikonglu.com 需先定怎么接。
