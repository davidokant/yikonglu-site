Las Analectas de Confucio 12.7子贡问政
子貢問政。子曰：足食。足兵。民信之矣。子貢曰：必不得已而去，於斯三者何先？曰：去兵。子貢曰：必不得已而去，於斯二者何先？曰：去食。自古皆有死，民無信不立。

兵和粮都能补，信一丢就站不住；做生意、管一方都一样。今例：开了二十年的小店，货断了能补，钱紧了能借，客人一旦觉得你骗过他一次，门就关了。
