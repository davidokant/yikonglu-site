照朱熹《筮仪》起一卦 · 试运营问易

陆川

问什么事，写下来。卦起出来是什么，我原样给你，不添一个字。

跑货的行商，规矩是“价可以喊，货不能编”。

初筮告，再三瀆，瀆則不告。

《周易·蒙》卦辞。同一件事只问一次，一天只起一卦。

你写的这句话只存在你自己这台手机或电脑的浏览器里，不会发给一孔录，也不会发给任何人。清掉浏览器数据就没了。

照朱熹《周易本义》书前《筮仪》和《系辞上》“大衍之数”一章，十八变一步不少。每一爻由你亲手分第一下，后两变照规矩接着走；第一爻会一步一步讲每个动作的意思。约两分钟。

进度

第一爻 · 第一变

《系辞上》

用手指在蓍草上划，松手的地方就是分开的地方。

该读哪一句

取法照朱熹《易学启蒙·考变占》七条。

这是你起出来的那一句。怎么读，你自己定。

卦帖

分享图里只有卦和爻辞，你写的问题不会进图。
