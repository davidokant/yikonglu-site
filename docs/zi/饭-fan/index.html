《论语》难字 · 全书 3 章“饭”读 fàn

饭fàn

《论语》里“饭”读 fàn 的，全书共 3 章。读音照朱熹《论语集注》定，和一孔录朗读一致。

朱熹怎么注

  • 饭，符晚反。饭，食之也。朱注，底本第 97 页（论语 7.15）
  • 饭，扶晚反。朱注，底本第 138 页（论语 10.13）

注文照朱熹《论语集注》（《四部备要》本）原文，页码是本站底本页码，点章号可以看原页。

全书 3 处

  1. 论语 7.15 饭疏食饮水子曰：饭疏食饮水，曲肱而枕之，乐亦在其中矣。
  2. 论语 10.13 事君侍食于君，君祭，先饭。
  3. 论语 18.9 大师挚适齐大师挚适齐，亚饭干适楚，三饭缭适蔡，四饭缺适秦。
