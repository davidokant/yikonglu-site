Wei zheng (livre 2) · chapitre 19Élever les droits

Ce que dit ce chapitre

Lecture de Yikonglu : Le peuple ne se soumet que si l'on emploie les bonnes personnes ; le difficile est de voir qui est droit. Aujourd'hui : une entreprise promeut celui qui n'apporte que de bonnes nouvelles, et laisse de côté celui qui travaille sérieusement et dit des vérités désagréables ; nul besoin de réunion, tout le monde en bas a compris.

白Chinois moderne

鲁哀公问：怎样做才能让百姓服从？孔子回答：提拔正直的人，放下那些不正直的人，百姓就服；提拔不正直的人，放下正直的人，百姓就不服。

注Les mots clés du commentaire

“错，舍置也” : cuo, placer ; “凡君问，皆称孔子对曰者，尊君也” : chaque fois qu'un prince interroge, le texte dit « Confucius répondit », par respect pour le prince.

说Ce que disent les autres commentateurs

Cheng Yi : “举错得宜，则人心服” : quand promotions et placements sont justes, les cœurs se soumettent ; Xie Liangzuo : “好直而恶枉，天下之至情也……然或无道以照之，则以直为枉、以枉为直者多矣” : tous aiment le droit et détestent le tordu, mais sans moyen d'y voir clair, beaucoup prennent l'un pour l'autre.
