Wei zheng (livre 2) · chapitre 4À quinze ans, je résolus d'apprendre

Ce que dit ce chapitre

Lecture de Yikonglu : Non pas un certificat délivré d'office à un certain âge, mais un chemin d'étude. La lecture courante dit « Un calendrier de vie classé par âge » ; Yikonglu place l'accent ailleurs.

白Chinois moderne

孔子说：我十五岁立志于学，三十岁能立得住，四十岁遇事不再疑惑，五十岁懂得天命，六十岁听到什么都能明白，七十岁随心所欲也不越出规矩。

常La lecture courante

Un calendrier de vie classé par âge.

注Les mots clés du commentaire

“心之所之谓之志” : zhi (la résolution), c'est là où va le cœur ; “于事物之所当然，皆无所疑” : aucun doute sur ce que les choses doivent être (plus de doutes) ; “天命……事物所以当然之故” : le mandat du Ciel est la raison pour laquelle les choses doivent être ainsi ; “矩，法度之器” : ju est l'équerre du charpentier, l'instrument de la mesure.

说Ce que disent les autres commentateurs

Cheng Yi : “圣人未必然，但为学者立法，使之盈科而后进” : le sage n'a pas forcément été ainsi lui-même ; il pose une règle pour ceux qui apprennent, afin qu'ils remplissent chaque creux avant d'avancer ; note de Zhu Xi : “因其近似以自名” : il a nommé les étapes d'après ce à quoi elles ressemblaient.
