Wei zheng (livre 2) · chapitre 11Revoir l'ancien pour connaître le nouveau

白Chinois moderne

孔子说：温习旧有的知识，每次都能有新的体会，就可以做老师了。

Rendu en chinois moderne selon la lecture de Yikonglu.

常La lecture courante

Réviser ses leçons.

注Les mots clés du commentaire

“温，寻绎也” : wen, c'est dévider le fil ; “故者，旧所闻；新者，今所得” : l'ancien est ce qu'on a entendu, le nouveau ce qu'on y gagne maintenant ; “记问之学，则无得于心” : le savoir appris par cœur ne gagne rien dans le cœur.

家Ce que disent les autres commentateurs

Zheng Xuan lit wen comme réchauffer de la viande froide.

读Comment Yikonglu le lit

Si l'on ne sait que réciter, réchauffer cent fois donne toujours le même bol.

家Autres commentaires

Notre texte de base est le commentaire de Zhu Xi (ci-dessus). Voici d'autres commentaires en regard : pour les anciens, la première phrase du sous-commentaire et un lien vers la xylographie ; pour les modernes, une seule phrase de traduction, citée brièvement.
