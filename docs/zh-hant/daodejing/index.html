《道德經》 · 已上 81 / 81 章道德經

王弼本八十一章：道經第 1—37 章，德經第 38—81 章。影片還在製作，網站先放原文、原頁、白話和注，開講後逐章補全。

道經（第 1—37 章）

  1. 1道可道未講道可道，非常道；名可名，非常名。無名，天地之始；有名，萬物之母。故常無欲，以觀其……
  2. 2天下皆知美之為美未講天下皆知美之為美，斯惡已；皆知善之為善，斯不善已。故有無相生，難易相成，長短相較……
  3. 3不尚賢未講不尚賢，使民不爭；不貴難得之貨，使民不為盜；不見可欲，使民心不亂。是以聖人之治，……
  4. 4道沖而用之或不盈未講道沖而用之或不盈，淵兮似萬物之宗。挫其銳，解其紛，和其光，同其塵，湛兮似或存。吾……
  5. 5天地不仁未講天地不仁，以萬物為芻狗；聖人不仁，以百姓為芻狗。天地之間，其猶橐籥乎？虛而不屈，……
  6. 6谷神不死未講谷神不死，是謂玄牝。玄牝之門，是謂天地根。綿綿若存，用之不勤。
  7. 7天長地久未講天長地久。天地所以能長且久者，以其不自生，故能長生。是以聖人後其身而身先，外其身……
  8. 8上善若水未講上善若水。水善利萬物而不爭，處衆人之所惡，故幾於道。居善地，心善淵，與善仁，言善……
  9. 9持而盈之未講持而盈之，不如其已；揣而棁之，不可長保。金玉滿堂，莫之能守；富貴而驕，自遺其咎。……
  10. 10載營魄抱一未講載營魄抱一，能無離乎？專氣致柔，能嬰兒乎？滌除玄覽，能無疵乎？愛民治國，能無知乎……
  11. 11三十輻共一轂未講三十輻共一轂，當其無，有車之用。埏埴以為器，當其無，有器之用。鑿戶牖以為室，當其……
  12. 12五色令人目盲未講五色令人目盲，五音令人耳聾，五味令人口爽，馳騁畋獵令人心發狂，難得之貨令人行妨。……
  13. 13寵辱若驚未講寵辱若驚，貴大患若身。何謂寵辱若驚？寵為下，得之若驚，失之若驚，是謂寵辱若驚。何……
  14. 14視之不見名曰夷未講視之不見名曰夷，聽之不聞名曰希，搏之不得名曰微。此三者不可致詰，故混而為一。其上……
  15. 15古之善為士者未講古之善為士者，微妙玄通，深不可識。夫唯不可識，故强為之容：豫焉若冬涉川，猶兮若畏……
  16. 16致虛極未講致虛極，守靜篤。萬物並作，吾以觀復。夫物芸芸，各復歸其根。歸根曰靜，是謂復命。復……
  17. 17太上未講太上，下知有之；其次，親而譽之；其次，畏之；其次，侮之。信不足焉，有不信焉。悠兮……
  18. 18大道廢未講大道廢，有仁義；慧智出，有大偽；六親不和，有孝慈；國家昏亂，有忠臣。
  19. 19絕聖棄智未講絕聖棄智，民利百倍；絕仁棄義，民復孝慈；絕巧棄利，盜賊無有。此三者以為文不足，故……
  20. 20絕學無憂未講絕學無憂。唯之與阿，相去幾何？善之與惡，相去若何？人之所畏，不可不畏。荒兮其未央……
  21. 21孔德之容未講孔德之容，惟道是從。道之為物，惟恍惟惚。惚兮恍兮，其中有象；恍兮惚兮，其中有物；……
  22. 22曲則全未講曲則全，枉則直，窪則盈，敝則新，少則得，多則惑。是以聖人抱一為天下式。不自見故明……
  23. 23希言自然未講希言自然。故飄風不終朝，驟雨不終日。孰為此者？天地。天地尚不能久，而況於人乎？故……
  24. 24企者不立未講企者不立，跨者不行，自見者不明，自是者不彰，自伐者無功，自矜者不長。其在道也，曰……
  25. 25有物混成未講有物混成，先天地生。寂兮寥兮，獨立不改，周行而不殆，可以為天下母。吾不知其名，字……
  26. 26重為輕根未講重為輕根，靜為躁君。是以聖人終日行不離輜重。雖有榮觀，燕處超然。奈何萬乘之主，而……
  27. 27善行無轍迹未講善行無轍迹，善言無瑕謫，善數不用籌策，善閉無關楗而不可開，善結無繩約而不可解。是……
  28. 28知其雄未講知其雄，守其雌，為天下谿。為天下谿，常德不離，復歸於嬰兒。知其白，守其黑，為天下……
  29. 29將欲取天下而為之未講將欲取天下而為之，吾見其不得已。天下神器，不可為也。為者敗之，執者失之。故物或行……
  30. 30以道佐人主者未講以道佐人主者，不以兵强天下，其事好還。師之所處，荊棘生焉；大軍之後，必有凶年。善……
  31. 31夫佳兵者未講夫佳兵者，不祥之器，物或惡之，故有道者不處。君子居則貴左，用兵則貴右。兵者不祥之……
  32. 32道常無名未講道常無名。樸雖小，天下莫能臣也。侯王若能守之，萬物將自賓。天地相合，以降甘露，民……
  33. 33知人者智未講知人者智，自知者明。勝人者有力，自勝者强。知足者富，强行者有志。不失其所者久，死……
  34. 34大道氾兮未講大道氾兮，其可左右。萬物恃之而生而不辭，功成不名有，衣養萬物而不為主。常無欲，可……
  35. 35執大象未講執大象，天下往。往而不害，安平太。樂與餌，過客止。道之出口，淡乎其無味，視之不足……
  36. 36將欲歙之未講將欲歙之，必固張之；將欲弱之，必固强之；將欲廢之，必固興之；將欲奪之，必固與之。……
  37. 37道常無為而無不為未講道常無為而無不為。侯王若能守之，萬物將自化。化而欲作，吾將鎮之以無名之樸。無名之……

德經（第 38—81 章）

  1. 38上德不德未講上德不德，是以有德；下德不失德，是以無德。上德無為而無以為，下德為之而有以為。上……
  2. 39昔之得一者未講昔之得一者：天得一以清，地得一以寧，神得一以靈，谷得一以盈，萬物得一以生，侯王得……
  3. 40反者道之動未講反者道之動，弱者道之用。天下萬物生於有，有生於無。
  4. 41上士聞道未講上士聞道，勤而行之；中士聞道，若存若亡；下士聞道，大笑之。不笑不足以為道。故建言……
  5. 42道生一未講道生一，一生二，二生三，三生萬物。萬物負陰而抱陽，沖氣以為和。人之所惡，唯孤、寡……
  6. 43天下之至柔未講天下之至柔，馳騁天下之至堅。無有入無間，吾是以知無為之有益。不言之教，無為之益，……
  7. 44名與身孰親未講名與身孰親？身與貨孰多？得與亡孰病？是故甚愛必大費，多藏必厚亡。知足不辱，知止不……
  8. 45大成若缺未講大成若缺，其用不弊。大盈若沖，其用不窮。大直若屈，大巧若拙，大辯若訥。躁勝寒，靜……
  9. 46天下有道未講天下有道，卻走馬以糞；天下無道，戎馬生於郊。禍莫大於不知足，咎莫大於欲得。故知足……
  10. 47不出戶未講不出戶，知天下；不闚牖，見天道。其出彌遠，其知彌少。是以聖人不行而知，不見而名，……
  11. 48為學日益未講為學日益，為道日損。損之又損，以至於無為，無為而無不為。取天下常以無事，及其有事……
  12. 49聖人無常心未講聖人無常心，以百姓心為心。善者吾善之，不善者吾亦善之，德善。信者吾信之，不信者吾……
  13. 50出生入死未講出生入死。生之徒十有三，死之徒十有三，人之生動之死地亦十有三。夫何故？以其生生之……
  14. 51道生之未講道生之，德畜之，物形之，勢成之。是以萬物莫不尊道而貴德。道之尊，德之貴，夫莫之命……
  15. 52天下有始未講天下有始，以為天下母。既得其母，以知其子；既知其子，復守其母，沒身不殆。塞其兌，……
  16. 53使我介然有知未講使我介然有知，行於大道，唯施是畏。大道甚夷，而民好徑。朝甚除，田甚蕪，倉甚虛；服……
  17. 54善建者不拔未講善建者不拔，善抱者不脫，子孫以祭祀不輟。修之於身，其德乃真；修之於家，其德乃餘；……
  18. 55含德之厚未講含德之厚，比於赤子。蜂蠆虺蛇不螫，猛獸不據，攫鳥不搏。骨弱筋柔而握固，未知牝牡之……
  19. 56知者不言未講知者不言，言者不知。塞其兌，閉其門，挫其銳，解其分，和其光，同其塵，是謂玄同。故……
  20. 57以正治國未講以正治國，以奇用兵，以無事取天下。吾何以知其然哉？以此。天下多忌諱，而民彌貧；民……
  21. 58其政悶悶未講其政悶悶，其民淳淳；其政察察，其民缺缺。禍兮福之所倚，福兮禍之所伏。孰知其極？其……
  22. 59治人事天莫若嗇未講治人事天莫若嗇。夫唯嗇，是謂早服。早服謂之重積德。重積德則無不克，無不克則莫知其……
  23. 60治大國若烹小鮮未講治大國若烹小鮮。以道蒞天下，其鬼不神。非其鬼不神，其神不傷人；非其神不傷人，聖人……
  24. 61大國者下流未講大國者下流，天下之交，天下之牝。牝常以靜勝牡，以靜為下。故大國以下小國，則取小國……
  25. 62道者萬物之奧未講道者萬物之奧，善人之寶，不善人之所保。美言可以市，尊行可以加人。人之不善，何棄之……
  26. 63為無為未講為無為，事無事，味無味。大小多少，報怨以德。圖難於其易，為大於其細。天下難事必作……
  27. 64其安易持未講其安易持，其未兆易謀，其脆易泮，其微易散。為之於未有，治之於未亂。合抱之木，生於……
  28. 65古之善為道者未講古之善為道者，非以明民，將以愚之。民之難治，以其智多。故以智治國，國之賊；不以智……
  29. 66江海所以能為百谷王者未講江海所以能為百谷王者，以其善下之，故能為百谷王。是以欲上民，必以言下之；欲先民，……
  30. 67天下皆謂我道大未講天下皆謂我道大，似不肖。夫唯大，故似不肖。若肖，久矣其細也夫！我有三寶，持而保之……
  31. 68善為士者不武未講善為士者不武，善戰者不怒，善勝敵者不與，善用人者為之下。是謂不爭之德，是謂用人之……
  32. 69用兵有言未講用兵有言：吾不敢為主而為客，不敢進寸而退尺。是謂行無行，攘無臂，扔無敵，執無兵。……
  33. 70吾言甚易知未講吾言甚易知，甚易行。天下莫能知，莫能行。言有宗，事有君。夫唯無知，是以不我知。知……
  34. 71知不知未講知不知，上；不知知，病。夫唯病病，是以不病。聖人不病，以其病病，是以不病。
  35. 72民不畏威未講民不畏威，則大威至。無狎其所居，無厭其所生。夫唯不厭，是以不厭。是以聖人自知不自……
  36. 73勇於敢則殺未講勇於敢則殺，勇於不敢則活。此兩者，或利或害。天之所惡，孰知其故？是以聖人猶難之。……
  37. 74民不畏死未講民不畏死，奈何以死懼之？若使民常畏死，而為奇者，吾得執而殺之，孰敢？常有司殺者殺……
  38. 75民之饑未講民之饑，以其上食稅之多，是以饑。民之難治，以其上之有為，是以難治。民之輕死，以其……
  39. 76人之生也柔弱未講人之生也柔弱，其死也堅强。萬物草木之生也柔脆，其死也枯槁。故堅强者死之徒，柔弱者……
  40. 77天之道未講天之道，其猶張弓與？高者抑之，下者舉之；有餘者損之，不足者補之。天之道，損有餘而……
  41. 78天下莫柔弱於水未講天下莫柔弱於水，而攻堅强者莫之能勝，其無以易之。弱之勝强，柔之勝剛，天下莫不知，……
  42. 79和大怨未講和大怨，必有餘怨，安可以為善？是以聖人執左契，而不責於人。有德司契，無德司徹。天……
  43. 80小國寡民未講小國寡民。使有什伯之器而不用，使民重死而不遠徙。雖有舟輿，無所乘之；雖有甲兵，無……
  44. 81信言不美未講信言不美，美言不信。善者不辯，辯者不善。知者不博，博者不知。聖人不積，既以為人己……
