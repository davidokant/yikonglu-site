  1. 5.22伯夷叔齊不念舊惡

    子曰：伯夷、叔齊不念舊惡，怨是用希。

    白話：孔子說：伯夷、叔齊不記著人家從前的過錯，所以別人對他們也就少有怨恨。

    底本：《四部備要》本《論語集註》第 72 頁

  2. 7.14夫子為衛君乎

    冉有曰：夫子為衛君乎？子貢曰：諾，吾將問之。入，曰：伯夷、叔齊何人也？曰：古之賢人也。曰：怨乎？曰：求仁而得仁，又何怨？出，曰：夫子不為也。

    白話：冉有說：老師會站在衛君那邊嗎？子貢說：嗯，我去問問。他進屋問：伯夷、叔齊算什麼樣的人？孔子答：古代的賢人。子貢又問：他們心裡有怨嗎？孔子說：一心求仁，仁也求到了，又怨什麼呢？子貢出來說：老師不會幫他。

    底本：《四部備要》本《論語集註》第 96、97 頁

  3. 16.12齊景公有馬千駟

    齊景公有馬千駟，死之日，民無德而稱焉。伯夷叔齊餓於首陽之下，民到於今稱之。其斯之謂與？

    白話：齊景公擁有四千匹馬，死時百姓卻沒有什麼德行可以稱頌，伯夷、叔齊餓死在首陽山下，百姓至今仍稱頌他們，說的大概就是這樣的事。

    底本：《四部備要》本《論語集註》第 228 頁

  4. 18.8逸民

    逸民：伯夷、叔齊、虞仲、夷逸、朱張、柳下惠、少連。子曰：不降其志，不辱其身，伯夷、叔齊與？謂：柳下惠、少連，降志辱身矣。言中倫，行中慮，其斯而已矣。謂：虞仲、夷逸，隱居放言。身中清，廢中權。我則異於是，無可無不可。

    白話：遺逸無位的人有伯夷、叔齊、虞仲、夷逸、朱張、柳下惠、少連，孔子說，不降低志向、不使自身受辱的是伯夷叔齊，柳下惠少連雖降志辱身，言論仍合義理、行動仍經得起思量，虞仲夷逸隱居、不談世事，自身合於清潔，棄仕合於權宜。孔子說自己與他們不同，沒有預定什麼必可、什麼必不可。
