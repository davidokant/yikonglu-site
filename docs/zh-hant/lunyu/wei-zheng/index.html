  1. 2.1為政以德不是不要政令，是治理者自己先有所得
  2. 2.2思無邪“無邪”在讀者，不全在詩
  3. 2.3道之以政刑政讓人遠罪，德禮讓人遷善
  4. 2.4吾十有五而志於學不是到歲數自動發的證書，是一條學的路。

  6. 2.6孟武伯問孝一句三讀並列
  7. 2.7子游問孝兩讀落點都是“敬”

  11. 2.11溫故而知新光背得出來，熱一百遍也還是那一碗。

  13. 2.13先行其言話還要說，只是放在後面。
  14. 2.14周而不比桌上的菜一模一樣，請客的理由不同。
  15. 2.15學而不思則罔一個是空，一個是懸
  16. 2.16攻乎異端照朱熹取“鑽進去有害”。
  17. 2.17知之為知之認下不知道，是起步。
  18. 2.18子張學干祿孔子沒有許諾，他把求官變成做人的功課。
  19. 2.19舉直錯諸枉難的是看清誰是直的
  20. 2.20臨之以莊則敬季康子問手段，孔子答本分
  21. 2.21子奚不為政話是託辭，道理也真。
  22. 2.22人而無信少了它，牛是牛，車是車，連不到一起。
  23. 2.23十世可知看了兩次交接，看哪些留下、哪些改了。
