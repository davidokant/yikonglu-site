  3. 12.3司馬牛問仁未講司馬牛問仁。子曰：仁者其言也訒。曰：其言也訒，斯謂之仁已乎？子曰：為之難，言之得……
  4. 12.4司馬牛問君子未講司馬牛問君子。子曰：君子不憂不懼。曰：不憂不懼，斯謂之君子已乎？子曰：內省不疚，……
  5. 12.5人皆有兄弟未講司馬牛憂曰：人皆有兄弟，我獨亡。子夏曰：商聞之矣：死生有命，富貴在天。君子敬而無……
  6. 12.6子張問明未講子張問明。子曰：浸潤之譖，膚受之愬，不行焉；可謂明也已矣。浸潤之譖，膚受之愬，不……

  8. 12.8君子質而已矣未講棘子成曰：君子質而已矣，何以文為？子貢曰：惜乎！夫子之說，君子也。駟不及舌。文猶……
  9. 12.9年飢未講哀公問於有若曰：年飢，用不足，如之何？有若對曰：盍徹乎？曰：二，吾猶不足，如之何……
  10. 12.10子張問崇德、辨惑未講子張問崇德、辨惑。子曰：主忠信，徙義，崇德也。愛之欲其生，惡之欲其死。既欲其生，……
  11. 12.11齊景公問政於孔子未講齊景公問政於孔子。孔子對曰：君君，臣臣，父父，子子。公曰：善哉！信如君不君，臣不……
  12. 12.12片言可以折獄者未講子曰：片言可以折獄者，其由也與？子路無宿諾。
  13. 12.13聽訟未講子曰：聽訟，吾猶人也，必也使無訟乎！
  14. 12.14子張問政未講子張問政。子曰：居之無倦，行之以忠。
  15. 12.15博學於文未講子曰：博學於文，約之以禮，亦可以弗畔矣夫！
  16. 12.16君子成人之美未講子曰：君子成人之美，不成人之惡。小人反是。
  17. 12.17季康子問政於孔子未講季康子問政於孔子。孔子對曰：政者，正也。子帥以正，孰敢不正？
  18. 12.18季康子患盜未講季康子患盜，問於孔子。孔子對曰：苟子之不欲，雖賞之不竊。
  19. 12.19如殺無道未講季康子問政於孔子曰：如殺無道，以就有道，何如？孔子對曰：子為政，焉用殺？子欲善，……

  21. 12.21樊遲從遊於舞雩之下未講樊遲從遊於舞雩之下，曰：敢問崇德、修慝、辨惑。子曰：善哉問！先事後得，非崇德與？……
  22. 12.22樊遲問仁未講樊遲問仁。子曰：愛人。問知。子曰：知人。樊遲未達。子曰：舉直錯諸枉，能使枉者直。……
  23. 12.23子貢問友未講子貢問友。子曰：忠告而善道之，不可則止，毋自辱焉。
