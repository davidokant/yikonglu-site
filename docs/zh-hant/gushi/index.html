故事

一孔錄的影片裡有六位原創人物陪著讀書，住在一張虛構的書區地圖上。這一欄介紹他們，只寫已經播出的內容；原文、注家和讀法都在章節頁，這裡不講。

片中人物

跟著一個人讀

跟著陸川讀義與利

買賣做久了，知道什麼都能開價；讀這些，是想看看哪些東西不該開價。

跟著林守拙讀做事與說話

手上會的比嘴上說得出的多，所以挑了這些講“先做、少說”的章。

跟著阮流綺讀樂與禮

跳舞的人最清楚，動作對了還不算，得知道為什麼這樣跳；這些章講的就是那個“為什麼”。

跟著莎赫拉讀為政與去國

走過幾個地方的人，讀這些講治國和遠行的章，想的東西會不一樣。

跟著上官有理讀言與行

話先說出去，再想辦法做到，這毛病書裡早有人犯過了，看看他是怎麼被說的。

跟著孔照今讀看與判斷

畫畫的人先學看，再學下筆；這些章講的是怎麼看人、看事，什麼時候該再看一眼。
