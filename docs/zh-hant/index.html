論語 7.10用之則行，舍之則藏
子謂顏淵曰：用之則行，舍之則藏；唯我與爾有是夫。子路曰：子行三軍，則誰與？子曰：暴虎馮河，死而無悔者，吾不與也。必也，臨事而懼，好謀而成者也。

出來做不為貪位，收起來不為只顧自己，心裡沒有非用不可的念頭才做得到；子路以勇自負，孔子要的是遇事知怕、肯謀劃、能辦成的人。今例：登山隊出發前一晚領隊一條條問怎麼撤，問得最細的人最敢上山。

近 7 天被抄走最多的一句

熱門章節

  1. 7.9子食於有喪者之側（是日哭則不歌）不是守規矩，是心裡真哀傷：挨著辦喪事的人吃不出味道，弔喪哭過的那天唱不出來。今例：參加完葬禮開車回家，音樂一響伸手就關了。
  2. 7.8不憤不啟，不悱不發上一集誰來都教，這一章講怎麼教：等學的人急到想通想說的時候再點
  3. 7.7自行束脩以上束脩是最薄的見面禮，重點不在學費，在“來學”：肯帶著禮主動來，孔子沒有不教的
  4. 7.6志於道，據於德，依於仁，遊於藝四步有先後輕重：先立志，再守得住，再不離仁，餘力在六藝裡遊，遊也不是閒玩，是讓心有處安放。今例：白天上班，晚上練一個鐘頭字，字不當飯吃，人不會散。
  5. 7.5甚矣吾衰也夢不見周公，不是心不向道了，是身子做不動、行道之心也隨之歇了
