論語 4.15吾道一以貫之
子曰：參乎！吾道一以貫之。曾子曰：唯。子出，門人問曰：何謂也？曾子曰：夫子之道，忠恕而已矣。

“忠恕”不是把道說盡了，是遞給學的人一個抓手；一以貫之只說給到了能懂時候的人；放到今天：老師傅帶新人只說一句——自己這道工序做到底，做完想想下一個接手的人。
