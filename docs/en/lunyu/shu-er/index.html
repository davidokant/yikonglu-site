  1. 7.1述而不作孔子删诗书、定礼乐，自认只是传旧
  2. 7.2默而识之默记在心、学不嫌够、教不嫌累，本不算圣人的顶点，孔子还说自己没做到，是谦上加谦。今例：夜里还在批作业的老师，被夸时说自己还差得远。
  3. 7.3德之不修四件都是天天要做的功夫，做不到就忧，圣人尚且如此，何况一般人。今例：说好不熬夜又拿起手机，真把手机放远了才算改。
  4. 7.4子之燕居不是孔子的话，是弟子记的样子：闲在家里身子舒展、脸色和悦，不端着也不瘫着。今例：周末在家笑着给阳台的花浇水。
  5. 7.5甚矣吾衰也梦不见周公，不是心不向道了，是身子做不动、行道之心也随之歇了
