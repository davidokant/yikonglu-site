Kitab › Lunyu (Analek)

Lunyu, kitab 11 · 0 dari 25 babXian jin (Kitab 11)

Setiap bab memuat teks asli, kata kunci dalam komentar, pendapat komentator lain, dan tafsir Yikonglu, beserta videonya.

  1. 11.1先进于礼乐belum dibahas子曰：先进于礼乐，野人也；后进于礼乐，君子也。如用之，则吾从先进。
  2. 11.2从我于陈、蔡者belum dibahas子曰：从我于陈、蔡者，皆不及门也。德行：颜渊，闵子骞，冉伯牛，仲弓。言语：宰我，……
  3. 11.3回也非助我者也belum dibahas子曰：回也非助我者也，于吾言无所不说。
  4. 11.4孝哉闵子骞belum dibahas子曰：孝哉闵子骞！人不间于其父母昆弟之言。
  5. 11.5南容三复白圭belum dibahas南容三复白圭，孔子以其兄之子妻之。
  6. 11.6季康子问belum dibahas季康子问：弟子孰为好学？孔子对曰：有颜回者好学，不幸短命死矣！今也则亡。
  7. 11.7颜渊死颜路请子之车以为之椁belum dibahas颜渊死，颜路请子之车以为之椁。子曰：才不才，亦各言其子也。鲤也死，有棺而无椁。吾……
  8. 11.8颜渊死子曰噫belum dibahas颜渊死。子曰：噫！天丧予！天丧予！
  9. 11.9颜渊死子哭之恸belum dibahas颜渊死，子哭之恸。从者曰：子恸矣。曰：有恸乎？非夫人之为恸而谁为！
  10. 11.10颜渊死门人欲厚葬之belum dibahas颜渊死，门人欲厚葬之，子曰：不可。门人厚葬之。子曰：回也视予犹父也，予不得视犹子……
  11. 11.11季路问事鬼神belum dibahas季路问事鬼神。子曰：未能事人，焉能事鬼？敢问死。曰：未知生，焉知死？
  12. 11.12闵子侍侧belum dibahas闵子侍侧，訚訚如也；子路，行行如也；冉有、子贡，侃侃如也。子乐。若由也，不得其死……
  13. 11.13鲁人为长府belum dibahas鲁人为长府。闵子骞曰：仍旧贯，如之何？何必改作？子曰：夫人不言，言必有中。
  14. 11.14由之瑟奚为于丘之门belum dibahas子曰：由之瑟奚为于丘之门？门人不敬子路。子曰：由也升堂矣，未入于室也。
  15. 11.15子贡问belum dibahas子贡问：师与商也孰贤？子曰：师也过，商也不及。曰：然则师愈与？子曰：过犹不及。
  16. 11.16季氏富于周公belum dibahas季氏富于周公，而求也为之聚敛而附益之。子曰：非吾徒也。小子鸣鼓而攻之，可也。
  17. 11.17柴也愚belum dibahas柴也愚，参也鲁，师也辟，由也喭。
  18. 11.18回也其庶乎belum dibahas子曰：回也其庶乎，屡空。赐不受命，而货殖焉，亿则屡中。
  19. 11.19子张问善人之道belum dibahas子张问善人之道。子曰：不践迹，亦不入于室。
  20. 11.20论笃是与belum dibahas子曰：论笃是与，君子者乎？色庄者乎？
  21. 11.21子路问belum dibahas子路问：闻斯行诸？子曰：有父兄在，如之何其闻斯行之？冉有问：闻斯行诸？子曰：闻斯……
  22. 11.22子畏于匡belum dibahas子畏于匡，颜渊后。子曰：吾以女为死矣。曰：子在，回何敢死？
  23. 11.23季子然问belum dibahas季子然问：仲由、冉求可谓大臣与？子曰：吾以子为异之问，曾由与求之问。所谓大臣者：……
  24. 11.24子路使子羔为费宰belum dibahas子路使子羔为费宰。子曰：贼夫人之子。子路曰：有民人焉，有社稷焉。何必读书，然后为……
  25. 11.25子路、曾皙、冉有、公西华侍坐belum dibahas子路、曾皙、冉有、公西华侍坐。子曰：以吾一日长乎尔，毋吾以也。居则曰：不吾知也！……
