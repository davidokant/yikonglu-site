Lunyu (Analek) 7.10用之则行，舍之则藏
子谓颜渊曰：用之则行，舍之则藏；唯我与尔有是夫。子路曰：子行三军，则谁与？子曰：暴虎冯河，死而无悔者，吾不与也。必也，临事而惧，好谋而成者也。

出来做不为贪位，收起来不为只顾自己，心里没有非用不可的念头才做得到；子路以勇自负，孔子要的是遇事知怕、肯谋划、能办成的人。今例：登山队出发前一晚领队一条条问怎么撤，问得最细的人最敢上山。

Bab paling banyak dibaca

  1. 7.9子食于有丧者之侧（是日哭则不歌）不是守规矩，是心里真哀伤：挨着办丧事的人吃不出味道，吊丧哭过的那天唱不出来。今例：参加完葬礼开车回家，音乐一响伸手就关了。
  2. 7.8不愤不启，不悱不发上一集谁来都教，这一章讲怎么教：等学的人急到想通想说的时候再点
  3. 7.7自行束脩以上束脩是最薄的见面礼，重点不在学费，在“来学”：肯带着礼主动来，孔子没有不教的
  4. 7.6志于道，据于德，依于仁，游于艺四步有先后轻重：先立志，再守得住，再不离仁，余力在六艺里游，游也不是闲玩，是让心有处安放。今例：白天上班，晚上练一个钟头字，字不当饭吃，人不会散。
  5. 7.5甚矣吾衰也梦不见周公，不是心不向道了，是身子做不动、行道之心也随之歇了
