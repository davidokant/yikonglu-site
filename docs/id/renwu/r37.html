Bab-bab dalam Analek

  1. 5.4Yong manusiawi tapi tak pandai bersilat lidah

    或曰：雍也仁而不佞。子曰：焉用佞？御人以口給，屢憎於人。不知其仁，焉用佞？

  2. 6.1Mengapa urusan boleh sederhana tetapi hati tidak?

    子曰：雍也可使南面。仲弓問子桑伯子。子曰：可也簡。仲弓曰：居敬而行簡，以臨其民，不亦可乎？居簡而行簡，無乃大簡乎？子曰：雍之言然。

  3. 6.4Bolehkah orang berlatar buruk dipakai?

    子謂仲弓曰：犁牛之子騂且角，雖欲勿用，山川其舍諸？

  4. 11.2从我于陈蔡

    子曰：從我於陳、蔡者，皆不及門也。德行：顏淵，閔子騫，冉伯牛，仲弓。言語：宰我，子貢。政事：冉有，季路。文學：子游，子夏。

  5. 12.2仲弓问仁

    仲弓問仁。子曰：出門如見大賓，使民如承大祭。己所不欲，勿施於人。在邦無怨，在家無怨。仲弓曰：雍雖不敏，請事斯語矣。

  6. 13.2仲弓为季氏宰

    仲弓為季氏宰，問政。子曰：先有司，赦小過，舉賢才。曰：焉知賢才而舉之？曰：舉爾所知。爾所不知，人其舍諸？
