跟着莎赫拉读

为政与去国

走过几个地方的人，读这些讲治国和远行的章，想的东西会不一样。——莎赫拉

下面是原文与章节页链接；人物只在这一句导语里出现，读法以章节页为准。

  1. 2.1为政以德

    子曰：为政以德，譬如北辰，居其所而众星共之。

  2. 2.3道之以政

    子曰：道之以政，齐之以刑，民免而无耻；道之以德，齐之以礼，有耻且格。

  3. 3.5夷狄之有君

    子曰：夷狄之有君，不如诸夏之亡也。

  4. 5.6道不行，乘桴浮于海

    子曰：道不行，乘桴浮于海。从我者，其由与？子路闻之喜。子曰：由也好勇过我，无所取材。
