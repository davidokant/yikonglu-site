《论语》

免费 · 不用注册 · 不用密钥在智器里查《论语》

一孔录有一个公开的连接器。把它加进 Claude 等智器（AI 助手），问起《论语》，智器就能直接查一孔录：原文、白话、朱熹《论语集注》的引文和原书页码，还有原页图，每次都附上本章网址，回来就能核对。

连接器地址

https://yikonglu-mcp.yikonglu.workers.dev/mcp

这是一个标准的 MCP 远程连接器（Streamable HTTP）。中国大陆部分网络可能连不上这个地址。

能查什么

按字句查（lunyu_search）给章号（如 1.1）或几个字（如“学而时习之”），找到对应的章，返回原文和网址。
取一章（lunyu_chapter）一章的原文、底本页码和原页图。已经讲读过的章，另有分句、白话、一孔之见、朱熹注引文。
这一章连着哪里（lunyu_related）书内互见、同问异答、人物、场合、和《三字经》《道德经》等书的对读、异文、读法之争。
今天读哪一章（lunyu_today）《论语》年历：一年读完全书，每天一课。不给日期就是今天。

底本是朱熹《论语集注》（《四部备要》本），全书 498 章，分章和章号与本站一致。

怎么加

Claude（网页版、桌面版）

  1. 打开“设置”里的“连接器”（Connectors）。
  2. 选“添加自定义连接器”，名称填“一孔录”，地址粘贴上面那一行。
  3. 回到对话，在工具菜单里打开“一孔录”，就可以问了。

Claude Code

claude mcp add --transport http yikonglu https://yikonglu-mcp.yikonglu.workers.dev/mcp

Cursor、VS Code 等支持 MCP 的工具

在 MCP 配置里加一项，名称 yikonglu，类型选 HTTP，地址同上。例如：

{
  "mcpServers": {
    "yikonglu": { "url": "https://yikonglu-mcp.yikonglu.workers.dev/mcp" }
  }
}

VS Code 的 .vscode/mcp.json 写成 "servers": { "yikonglu": { "type": "http", "url": "…" } }。

试着这样问

  • 今天该读《论语》哪一章？
  • “学而时习之，不亦说乎”的“说”怎么读？朱熹怎么注？
  • 子路问过孔子哪些事？
  • “克己复礼”在朱熹《论语集注》原书第几页？给我看原页。

引用请署名

连接器里的内容按 CC BY 4.0 开放，智器转述、个人文章、视频引用都可以，请署“一孔录 yikonglu.com”，并附该章网址，例如：

出处：一孔录 yikonglu.com，https://yikonglu.com/lunyu/1.1

连接器每次返回的结果里都带着这一行和本章网址，照着写即可。

发现错了

连接器和网站用的是同一份底子，网站改了，连接器跟着改。看到错字、错页码，请到勘误页告诉我们，改过会公开记录。
