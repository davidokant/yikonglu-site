论语 9.27岁寒
子曰：岁寒，然后知松柏之后彫也。

说的是人不是树：太平日子里大家看着差不多，碰上利害、遇到变故，谁守得住才分得出来。今例：洪水那一夜能撤的都撤了，值班护士一间一间病房守到天亮。
