论语 7.10用之则行，舍之则藏
子谓颜渊曰：用之则行，舍之则藏；唯我与尔有是夫。子路曰：子行三军，则谁与？子曰：暴虎冯河，死而无悔者，吾不与也。必也，临事而惧，好谋而成者也。

出来做不为贪位，收起来不为只顾自己，心里没有非用不可的念头才做得到；子路以勇自负，孔子要的是遇事知怕、肯谋划、能办成的人。今例：登山队出发前一晚领队一条条问怎么撤，问得最细的人最敢上山。
