论语 4.15吾道一以贯之
子曰：参乎！吾道一以贯之。曾子曰：唯。子出，门人问曰：何谓也？曾子曰：夫子之道，忠恕而已矣。

“忠恕”不是把道说尽了，是递给学的人一个抓手；一以贯之只说给到了能懂时候的人；放到今天：老师傅带新人只说一句——自己这道工序做到底，做完想想下一个接手的人。
