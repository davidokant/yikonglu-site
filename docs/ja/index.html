最近の収録

  1. 4.7人の過ちや、各々其の黨に於てす過ちが厚すぎる方か薄すぎる方かで、仁か不仁かが見える。今日に置けば：同じ三十分の遅刻でも、一人は転んだ老人を病院に送り、一人は寝坊した。
  2. 4.6我未だ仁を好む者を見ず心の行く所に力も行く。難しいのは力ではなく、用いる気があるかどうか。今日に置けば：運動する時間がないと言う人が、寝る前に二時間スマホを眺めている。
  3. 4.5富と貴とは、是れ人の欲する所なり来るべきでない富貴は受けず、落ちてくるべきでない貧賤も曲がった道で避けない。大きな分かれ道と一食の間の小さな工夫が互いを成り立たせる。今日に置けば：バスが急ブレーキをかけた時、若者が真っ先に手を伸ばして支えたのは隣のおばあさんだった。
  4. 4.4苟くも仁に志せば、悪無し志は間違いをしない保証ではない。保証するのは、わざと悪をしないこと。今日に置けば：教習中の人が一年で三回車をこすったが、赤信号は一度も無視していない。
  5. 4.3唯だ仁者のみ能く人を好み、能く人を悪む好き嫌いは誰にでもある。「能く」は理にかなうことで、その前提は心が何にも繋がれていないこと。今日に置けば：コンクールの審査員が、自分の教え子が舞台に上がると席を立ち、その回は採点しない。
  6. 4.2不仁者は以て久しく約に処るべからず長く困窮すれば分を越え、長く楽しめば度を越す。外の物に人が奪われるかどうかは、本心があるかどうか。今日に置けば：半年失業している人が、毎朝七時に起きてひげを剃り、外へ走りに出る。
