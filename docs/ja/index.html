最新の章

論語 5.4雍や仁にして佞ならず
或曰：雍也仁而不佞。子曰：焉用佞？御人以口给，屡憎于人。不知其仁，焉用佞？

病根は「実がない」こと。口が速く弁が立っても中身がなければ、言うほど嫌われる。孔子が仲弓に仁を許さないのは、仁が大きすぎて軽々しく許さないから。今日に置けば：何でも引き受け何でも約束して何一つ実行しない人を、三か月後には同僚が避けて通る。

最近読んだ章

  1. 6.19孔子のこの言葉は、人を見下しているのか人の上下を分けているのではなく、相手を見て話すということ。高すぎる話は受け止められず、かえって害になる。材に応じて教え、一歩ずつ上へ進む。
  2. 6.18知る・好む・楽しむ、どこが違うのかこの飯があると知ること、この飯を好んで食べること、食べて満ち足り心が落ち着くこと。三つの段階だ。違いは知識の多さではなく、得たかどうかにある。
  3. 6.17まっすぐでない人も、ちゃんと生きているのでは人はもともとまっすぐに生きるもの。まっすぐでない人も生きているが、それは当然ではなく、運よく逃れているだけだ。
  4. 6.16野暮すぎと飾りすぎ、孔子はどちらを取るか素朴すぎれば野暮、飾りすぎれば空虚、両者が釣り合ってこそ君子。偏るなら野暮のほうがよい。土台があれば文を加えられるが、土台がなければ文の置き場もない。
  5. 6.15出るときは戸を通るのに、なぜ正しい道を通らないのか外に出るのに誰もが戸を通り、塀を越えはしない。生き方の正道も目の前にあるのに、あえて通らない。道が人から遠いのではなく、人が自分で遠ざかったのだ。
