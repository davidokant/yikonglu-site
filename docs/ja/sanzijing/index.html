『三字経』千二百字・百一組を、一孔録『三字経・父の講義』に沿って三十九講に分け、週に一講ずつ読みます。各講に原文、底本の王相『三字経訓詁』（1831 年和刻本）の原本画像（組ごとに枠表示）、朗読、日本語訳（初稿）を載せています。

  3. 3玉磨かざれば未講玉は磨かなければ器にならない。人は学ばなければ、なすべき道を知らない。 人の子として、まだ年若いうちに、師や友に親しみ、礼儀を身につけよ。

巻三・数を知る（第 5—11 講）

  1. 5一から十へ未講一から十、十から百、百から千、千から万。 三才とは天・地・人。三光とは日・月・星。 三綱とは、君臣には義、父子には親しみ、夫婦には和順。
  2. 6四時と四方未講春と夏、秋と冬、この四時はめぐって尽きることがない。 南と北、西と東、この四方は中央を基準に定まる。
  3. 7五行と五常未講水と火、木・金・土、この五行は数にもとづく。 仁と義、礼・智・信、この五常は乱してはならない。
  4. 8六穀と六畜未講稲・粱・菽（豆）、麦・黍・稷、この六穀は人の食べるものである。 馬・牛・羊、鶏・犬・豚、この六畜は人の飼うものである。

  7. 11九族と十義未講高祖・曽祖・祖父、父、そして自分。自分から子へ、子から孫へ。 子と孫から、玄孫・曽孫まで、これが九族であり、人の倫（つながり）の順序である。…

  6. 17諸子未講経書が明らかになってから諸子を読む。要点をつまみ、その事柄を覚える。 五子とは、荀子と揚雄、文中子、そして老子と荘子である。
