朱熹《论语集注》（宋）

Base edition
《四部备要》本《论语集注》。本站原文与注的底本，视频里的朱注原页也用这一本。
Images
工坊所藏该本影印扫描；本站“底本原页”是同一扫描压缩后的图。
Pages
“原页 N”是扫描文件的第 N 页（从 1 起算），不是原书叶码。
License
原书是公版。原页图只作核对展示。
How we use it
每章原文、注里的关键字、引文逐条核对表都据此本；转述和原话分开标。

皇侃《论语义疏》（梁）

Base edition
知不足斋丛书第七集本《论语集解义疏》卷一、二（题魏何晏集解、梁皇侃义疏）。书目著录的乾隆五十三年（1788）是序年，扫描的具体印次未定。
Images
Wikimedia Commons 影印扫描（共 164 页）。
Pages
“原刻本扫描第 N 页”是该扫描文件的第 N 页（从 1 起算）；卷一第一叶正面是第 29 页，背面第 30 页，以下按版心正背推。
License
公版。
How we use it
每章录疏文第一个完整释义单元，句读是一孔录加的；全文请点扫描页看原刻。

Base edition

Images

Pages

License
公版。
How we use it
