各章に、原文、注の要となる語、諸家の説、一孔録の読みを、動画とともに。

  1. 14.1憲が恥を問うた未講憲が恥を問うた。先生「国に道があっても禄を食み、国に道がなくても禄を食む。それが恥である。」
  2. 14.2人に勝とうとすること、誇ること、恨むこと、欲張…未講「人に勝とうとすること、誇ること、恨むこと、欲張ることが行われなければ、仁と言えますか。」先生「難しいことだとは言えるが、仁かどうかは私にはわからない。」
  3. 14.3士でありながら住み心地を思うようでは、士とする…未講先生が言われた。士でありながら住み心地を思うようでは、士とするに足りない。
  4. 14.4国に道があれば、言葉を高く行いを高くする未講先生が言われた。国に道があれば、言葉を高く行いを高くする。国に道がなければ、行いは高くして言葉は控えめにする。
  5. 14.5徳のある者には必ずよい言葉があるが、言葉のある…未講先生が言われた。徳のある者には必ずよい言葉があるが、言葉のある者に必ず徳があるとは限らない。仁者には必ず勇があるが、勇者に必ず仁があるとは限らない。
  6. 14.6南宮适が孔子に問うた未講南宮适が孔子に問うた。「羿は弓が巧みで、奡は陸で舟を押し動かしたが、どちらもまともな死に方をしなかった。禹と稷は自ら耕して天下を有した。」先生は答えられなかった。南宮适が出ていくと…
  7. 14.7君子でも仁でない者はいるだろうが、小人で仁であ…未講先生が言われた。君子でも仁でない者はいるだろうが、小人で仁である者はいない。
  8. 14.8愛するなら、苦労させずにいられようか未講先生が言われた。愛するなら、苦労させずにいられようか。忠であるなら、教え諭さずにいられようか。
  9. 14.9外交文書を作るとき、裨諶が草稿を作り、世叔が検…未講先生が言われた。外交文書を作るとき、裨諶が草稿を作り、世叔が検討し、行人の子羽が修正し、東里の子産が仕上げの潤色をした。

  11. 14.11貧しくて恨まないのは難しく、富んで驕らないのは…未講先生が言われた。貧しくて恨まないのは難しく、富んで驕らないのはやさしい。
  12. 14.12孟公綽は趙・魏の家老なら余裕があるが、滕・薛の…未講先生が言われた。孟公綽は趙・魏の家老なら余裕があるが、滕・薛の大夫にはなれない。
  13. 14.13子路が成人を問うた未講子路が成人を問うた。先生「臧武仲の知、公綽の無欲、卞荘子の勇、冉求の芸があり、それを礼楽で飾れば、成人と言えよう。」さらに言われた。「今の成人は、そこまで必要だろうか。利を見ては義…
  14. 14.14先生が公明賈に公叔文子のことを問うた未講先生が公明賈に公叔文子のことを問うた。「本当ですか、あの方は言わず、笑わず、取らないというのは。」公明賈「伝えた者が言い過ぎです。あの方は時を得てから言うので、人はその言葉を嫌がり…
  15. 14.15臧武仲は防に拠って、魯に後継ぎを立てることを求…未講先生が言われた。臧武仲は防に拠って、魯に後継ぎを立てることを求めた。君主を脅したのではないと言っても、私は信じない。
  16. 14.16晋の文公は謀略を用いて正しくなく、斉の桓公は正…未講先生が言われた。晋の文公は謀略を用いて正しくなく、斉の桓公は正しくて謀略を用いなかった。
  17. 14.17桓公が公子糾を殺したとき、召忽は殉じたが、管仲…未講子路が言った。「桓公が公子糾を殺したとき、召忽は殉じたが、管仲は死ななかった。仁ではないのでは。」先生「桓公が諸侯を九たび会合させて、兵車を用いなかったのは、管仲の力だ。それこそ彼…

  19. 14.19公叔文子の家臣の大夫僎は、文子とともに公朝に昇…未講公叔文子の家臣の大夫僎は、文子とともに公朝に昇った。先生はこれを聞いて言われた。「文と諡されるにふさわしい。」

  24. 14.24君子は上に達し、小人は下に達する未講先生が言われた。君子は上に達し、小人は下に達する。
  25. 14.25昔の学ぶ者は自分のために学び、今の学ぶ者は人に…未講先生が言われた。昔の学ぶ者は自分のために学び、今の学ぶ者は人に見せるために学ぶ。

  28. 14.28君子は思うことがその地位を出ない未講曾子が言った。君子は思うことがその地位を出ない。
  29. 14.29君子は言葉が行いを上回ることを恥じる未講先生が言われた。君子は言葉が行いを上回ることを恥じる。
  30. 14.30君子の道は三つあるが、私はどれもできない未講先生が言われた。君子の道は三つあるが、私はどれもできない。仁者は憂えず、知者は惑わず、勇者は懼れない。子貢「それは先生がご自分のことを言われたのです。」
  31. 14.31子貢が人を比べて評していた未講子貢が人を比べて評していた。先生「賜は賢いのだな。私にはそんな暇はない。」
  32. 14.32人が自分を知らないことを憂えず、自分にその能力…未講先生が言われた。人が自分を知らないことを憂えず、自分にその能力がないことを憂える。
  33. 14.33偽りを予期せず、不信を推測しない未講先生が言われた。偽りを予期せず、不信を推測しない。それでいて先に気づく。これこそ賢いのだ。
  34. 14.34微生畝が孔子に言った未講微生畝が孔子に言った。「丘よ、どうしてそうせわしなく動き回るのか。口先がうまいだけではないのか。」孔子「口先をうまくしようなどとは思いません。頑固なのが嫌なのです。」
  35. 14.35名馬はその力を称えられるのではなく、その徳を称…未講先生が言われた。名馬はその力を称えられるのではなく、その徳を称えられるのだ。
  36. 14.36徳をもって怨みに報いるのはどうですか未講ある人が言った。「徳をもって怨みに報いるのはどうですか。」先生「では何をもって徳に報いるのか。直をもって怨みに報い、徳をもって徳に報いる。」
  37. 14.37私を知る者はいないな未講先生が言われた。「私を知る者はいないな。」子貢「どうして先生を知る者がいないのですか。」先生「天を怨まず、人をとがめず、下学して上達する。私を知るのは天であろうか。」

  40. 14.40そうした者は七人いる未講先生が言われた。そうした者は七人いる。
