论语 20.3 · 尧曰不知命无以为君子

白白话：“不知命”是什么意思

《论语》20.3 全章“子曰：不知命，无以为君子也。不知礼，无以立也。不知言，无以知人也。”的白话：孔子说，不懂天命，不能成为君子，不懂礼，不能立身，不懂分辨言语，就不能了解人。（一孔录的读法；一孔录 yikonglu.com/lunyu/20.3）

这一章讲什么

一孔之见：《论语》20.3“不知命无以为君子”，一本书读完一遍不算读完，《论语》是一辈子带在身边、遇事拿出来用的书。今例：面试官先听人说话，一开口全是前同事的不是，不要。常有人问“《论语》最后一句，为什么落在知命、知礼、知言上”，上面是一孔录的回答。（朱熹《论语集注》《四部备要》本第 265 页；一孔录 yikonglu.com/lunyu/20.3）

常常见的理解

《论语》最后一句，为什么落在知命、知礼、知言上？

注注里的关键字

“不知礼，则耳目无所加，手足无所措”；“言之得失，可以知人之邪正”。

说诸家怎么说

程子“知命者，知有命而信之也。人不知命，则见害必避，见利必趋，何以为君子”；尹氏“知斯三者，则君子之事备矣。弟子记此以终篇，得无意乎”，又说读了一辈子却不觉得有一句可用，“不几于侮圣言者乎？夫子之罪人也，可不念哉”。《集解》引孔安国“命谓穷达之分”；马融“听言则别其是非也”。

与朱注异同

注本关键处异同把握说明
杨伯峻《论语译注》同解定知命知礼知言才能为君子、立身知人；知言辨言语得失邪正，杨明联孟子，不是仅懂字面语法。
钱穆《论语新解》同解较稳同以知命信有命可不避义趋利、知礼立身、知言识人。钱分天命积极消极诸义，并疑末章编次来源；朱重点知命而信、礼约行、言得失可知人。
