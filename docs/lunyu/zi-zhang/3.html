论语 19.3 · 子张子夏之门人问交于子张

白白话：“子夏之门人问交于子张”是什么意思

《论语》19.3 全章“子夏之门人问交于子张。子张曰：子夏云何？对曰：子夏曰：可者与之，其不可者拒之。子张曰：异乎吾所闻：君子尊贤而容众，嘉善而矜不能。我之大贤与，于人何所不容？我之不贤与，人将拒我，如之何其拒人也？”的白话：子夏的学生向子张问交友，转述子夏“可交者交，不可交者拒”的话，子张说，自己听到的不同，君子尊敬贤人而容纳众人，嘉奖善者而体谅能力不足者。自己若很贤，何人不能容纳，自己若不贤，别人将拒绝自己，又如何拒绝别人。（一孔录的读法；一孔录 yikonglu.com/lunyu/19.3）

这一章讲什么

一孔之见：《论语》19.3“子夏之门人问交于子张”，一孔之见：朋友圈可以大，饭桌要小；来往的人照子张，客客气气，交心、合伙、借钱的人照子夏，挑了再挑。今例：咖啡馆店门对谁都开，账本只给一个人看。常有人问：交朋友该“不可者拒之”，还是“尊贤而容众”？上面是一孔录的回答。（朱熹《论语集注》《四部备要》本第 253 页；一孔录 yikonglu.com/lunyu/19.3）

常常见的理解

交朋友该“不可者拒之”，还是“尊贤而容众”？

注注里的关键字

“子夏之言迫狭，子张讥之是也。但其所言亦有过高之弊。盖大贤虽无所不容，然大故亦所当绝；不贤固不可以拒人，然损友亦所当远。学者不可不察”。

说诸家怎么说

《集解》引包咸“友交当如子夏，汎交当如子张”。

注本关键处异同把握说明
杨伯峻《论语译注》交友字义不同较稳子张宽容之译相同，朱再指出子夏过狭、子张亦过高，有大故损友当绝远；杨无明注作此双方批评。
