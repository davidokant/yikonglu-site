《论语》第 8 篇 · 已讲 0 / 21 章泰伯第八

每章有原文、注里的关键字、诸家说法和一孔录的读法，附视频。

  1. 8.1泰伯未讲子曰：泰伯，其可谓至德也已矣！三以天下让，民无得而称焉。
  2. 8.2恭而无礼则劳未讲子曰：恭而无礼则劳，慎而无礼则葸，勇而无礼则乱，直而无礼则绞。君子笃于亲，则民兴……
  3. 8.3曾子有疾召门弟子曰启予足未讲曾子有疾，召门弟子曰：启予足！启予手！诗云战战兢兢，如临深渊，如履薄冰。而今而后……
  4. 8.4曾子有疾孟敬子问之未讲曾子有疾，孟敬子问之。曾子言曰：鸟之将死，其鸣也哀；人之将死，其言也善。君子所贵……
  5. 8.5以能问于不能未讲曾子曰：以能问于不能，以多问于寡；有若无，实若虚；犯而不校。昔者吾友尝从事于斯矣……
  6. 8.6可以托六尺之孤未讲曾子曰：可以托六尺之孤，可以寄百里之命，临大节而不可夺也。君子人与？君子人也。
  7. 8.7士不可以不弘毅未讲曾子曰：士不可以不弘毅，任重而道远。仁以为己任，不亦重乎？死而后已，不亦远乎？
  8. 8.8兴于诗未讲子曰：兴于诗，立于礼。成于乐。
  9. 8.9民可使由之未讲子曰：民可使由之，不可使知之。
  10. 8.10好勇疾贫未讲子曰：好勇疾贫，乱也。人而不仁，疾之已甚，乱也。
  11. 8.11如有周公之才之美未讲子曰：如有周公之才之美，使骄且吝，其余不足观也已。
  12. 8.12三年学未讲子曰：三年学，不至于谷，不易得也。
  13. 8.13笃信好学未讲子曰：笃信好学，守死善道。危邦不入，乱邦不居。天下有道则见，无道则隐。邦有道，贫……
  14. 8.14不在其位未讲子曰：不在其位，不谋其政。
  15. 8.15师挚之始未讲子曰：师挚之始，关雎之乱，洋洋乎！盈耳哉。
  16. 8.16狂而不直未讲子曰：狂而不直，侗而不愿，悾悾而不信，吾不知之矣。
  17. 8.17学如不及未讲子曰：学如不及，犹恐失之。
  18. 8.18巍巍乎未讲子曰：巍巍乎！舜禹之有天下也，而不与焉。
  19. 8.19大哉未讲子曰：大哉！尧之为君也。巍巍乎！唯天为大，唯尧则之。荡荡乎！民无能名焉。巍巍乎！……
  20. 8.20舜有臣五人而天下治未讲舜有臣五人而天下治。武王曰：予有乱臣十人。孔子曰：才难，不其然乎？唐、虞之际，于……
  21. 8.21禹吾无间然矣未讲子曰：禹，吾无间然矣。菲饮食，而致孝乎鬼神；恶衣服，而致美乎黻冕；卑宫室，而尽力……
