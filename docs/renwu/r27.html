看管仲出场各章与常同章的人 ›

《论语》出场各章

  1. 3.22管仲之器小哉

    子曰：管仲之器小哉！或曰：管仲俭乎？曰：管氏有三归，官事不摄，焉得俭？然则管仲知礼乎？曰：邦君树塞门，管氏亦树塞门；邦君为两君之好，有反坫，管氏亦有反坫。管氏而知礼，孰不知礼？

    白话：孔子说：管仲的器量真小啊！有人问：管仲节俭吗？孔子说：管氏有三归台，家里的官一人一职，怎么算节俭？那人又问：那管仲懂礼吗？孔子说：国君在门内立屏墙，管氏也立屏墙；国君为两国国君的友好会见，堂上设放酒杯的土台，管氏也设。管氏要是懂礼，还有谁不懂礼？

    底本：《四部备要》本《论语集注》第 47、48 页

  2. 14.10或问子产

    或问子产。子曰：惠人也。问子西。曰：彼哉！彼哉！问管仲。曰：人也。夺伯氏骈邑三百，饭疏食，没齿无怨言。

    白话：有人问子产，孔子说，他是惠爱人的人，问子西，孔子说，那个人啊，那个人啊。问管仲，孔子说，这个人啊，伯氏的骈邑三百户被夺来给了他，伯氏只能吃粗饭，却终身没有怨言。

    底本：《四部备要》本《论语集注》第 188、189 页

  3. 14.17子路疑管仲未仁

    子路曰：桓公杀公子纠，召忽死之，管仲不死。曰：未仁乎？子曰：桓公九合诸侯，不以兵车，管仲之力也。如其仁！如其仁！

    白话：子路说，桓公杀公子纠，召忽为他而死，管仲却不死，这算不上仁吧；孔子说，桓公督率诸侯会合，不靠兵车的威力，这是管仲的力量，谁能比得上他的仁德，谁能比得上呢！

    底本：《四部备要》本《论语集注》第 193 页

  4. 14.18子贡疑管仲非仁

    子贡曰：管仲非仁者与？桓公杀公子纠，不能死，又相之。子曰：管仲相桓公，霸诸侯，一匡天下，民到于今受其赐。微管仲，吾其被发左衽矣。岂若匹夫匹妇之为谅也，自经于沟渎而莫之知也。

    白话：子贡怀疑管仲不为公子纠死、又辅佐桓公不仁，孔子说，管仲辅佐桓公称霸诸侯，使天下归正，百姓到今天还受他的恩惠；没有管仲，我们恐怕已披发左衽了。哪里能像普通男女只守小信，自缢在沟渠里而没有人知道。

    底本：《四部备要》本《论语集注》第 194 页
